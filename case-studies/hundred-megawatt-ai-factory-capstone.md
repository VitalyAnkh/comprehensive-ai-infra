## 1. 工程背景：从孤立部件调优到 100 MW 智算工厂端到端联立方程

当基础模型迈入万亿至十万亿总参数的混合专家（MoE）时代、在线多步推理与异步可验证强化学习（RLVR）形成昼夜连续生产流时，基础设施的顶层硬约束不再是单一算子的微秒延迟或单张加速卡的峰值算力，而是**园区变电站批复的功率上限（如 $P_{\mathrm{grid}} = 100.0\ \mathrm{MW}$）、三年期全生命周期总拥有成本（TCO）与季度级（$\le 90$ 天）旗舰模型交付工期**。

在这一百兆瓦级物理边界下，本书五大部类并非彼此独立的知识模块，而是一组强耦合的联立约束：供电与液冷效率（第四部分 `Ch14`）直接决定可部署的超节点机柜总数（第二部分 `Ch04–Ch07`）；机柜在训练池、在线服务池与泊松热备池之间的切分比例（第四部分 `Ch15` 与第三部分 `Ch11`）同时支配旗舰预训练工期、有效训练时间比（ETTR）与日均词元吞吐；而模型激活参数稀疏度（第一部分 `Ch01–Ch03`）、原生低比特混合精度与 `PD/AF` 解耦服务（第三部分 `Ch08–Ch10`）以及 `RLVR` 算子自演进与昼夜波谷算力复用（第四/五部分 `Ch17–Ch24`）最终共同决定了每百万词元的净生产成本。

## 2. 100 MW 智算工厂五大部类基线账本

在 $P_{\mathrm{grid}} = 100.0\ \mathrm{MW}$ 园区供电红线与 `800V HVDC` 高压直流配电 + `ASHRAE W45` 温水液冷（$\mathrm{PUE} = 1.12$）基线下，端到端容量、工期与三年期财务账本如下：

| 架构部类与核算层级 | 关键设计参数与跨层机制 | 锁定定量结果 |
| :--- | :--- | :---: |
| **电热与 IT 功率切分（`Ch14`）** | $P_{\mathrm{IT}} = 100.0 / 1.12 = 89.29\ \mathrm{MW}$；Spine 光交换与 `3FS` 存储占 $7.45\ \mathrm{MW}$ | 超节点总供电 **$81.84\ \mathrm{MW}$** |
| **超节点机柜与卡池划分（`Ch06, 15`）** | 单柜 `72-GPU` 液冷功耗 $165.0\ \mathrm{kW}$，共 $496$ 柜（$35,712$ 张 GPU）：$400$ 柜训练 + $82$ 柜推理 + $14$ 柜整柜热备（含训练池内 $128$ 张热备卡） | 活跃训练 **$28,672$ 卡**；推理 **$5,904$ 卡**；总热备 **$1,136$ 卡（$3.18\%$，$\mathrm{ETTR}=97.6\%$）** |
| **持续有效算力与模型工期（`Ch01–03, 10, 17`）** | 单卡计入 `MFU=44.17%` 与 `ETTR=97.6%` 后持续有效算力 $970.0\ \mathrm{TFLOPS}$，全池持续算力 **$27.81\ \mathrm{EFLOPS}$** | `10T/380B`（$60\ \mathrm{T}$ 词元，$1.50\times 10^{26}\ \mathrm{FLOPs}$）预训练 **$62.4\ \mathrm{d}$** + `RLVR` **$18.5\ \mathrm{d}$** = **$80.9\ \mathrm{d}$**；`1T/44B`（$25\ \mathrm{T}$）仅 **$2.75\ \mathrm{d}$** |
| **双轨模型基线衔接（`Ch02, 13, 18`）** | 兼容 [`qwen3-8b`](../calculations/configs/models/qwen3-8b/config.json)、[`qwen3-235b-a22b`](../calculations/configs/models/qwen3-235b-a22b/config.json) 与 [`deepseek-v3`](../calculations/configs/models/deepseek-v3/config.json) / [`deepseek-v4.1-flash`](../calculations/configs/models/deepseek-v4.1-flash/config.json) 架构锚点 | 满配 `PD` 分离 + `Mooncake` KV 池 + `XGrammar` 在 $\mathrm{TTFT}\le 350\ \mathrm{ms}, \mathrm{TPOT}\le 20\ \mathrm{ms}$ 下日产 **$216.5\ \mathrm{B}$ 词元** |
| **三年期 TCO 与词元单价（`Ch11, 24`）** | 三年硬件与机电 CapEx $1{,}860.00\mathrm{M\ USD}$ + 电费 OpEx $170.82\mathrm{M\ USD}$（$65\ \mathrm{USD/MWh}$）= **$2{,}030.82\mathrm{M\ USD}$** | 全池摊销 **$2.16\ \mathrm{USD/(GPU\cdot h)}$**；纯推理池摊销 **$1.41\ \mathrm{USD/1M\ tok}$**，波谷 $56.7\%$ 算力执行异步 `RL` 后净成本 **$0.61\ \mathrm{USD/1M\ tok}$** |

同时，在单流极低延迟服务区（第 23.6.1 节算例 23-20），全片上 `SRAM` 阵列在 $B=1$ 下可将 `70B FP8` 解码推至 $1,850.0\ \mathrm{tok/s}$（较 `4×H100` 的 $164.7\ \mathrm{tok/s}$ 提速 $11.23\times$），但其与 `HBM` 系统的单位词元成本盈亏平衡并发度精确落在 $B_{\mathrm{cross}} = 14.2$；当在线并发扩至 $B=128$ 时，`HBM` 超节点反而具备 $6.8\times$ 的单位吞吐成本优势，从而从定量上确立了“高频交互草稿走片上 `SRAM`、大吞吐主干与批量采样走 `HBM` 超节点”的异构分区原则。

## 3. 四大物理守恒律端到端效率瀑布与三组反事实压力测试

通过 `experiments/ch24/24-06/run.py` 进一步对工厂施加风冷退化、电价冲击与显存减半三组反事实扰动，可以清晰观测跨层联立补偿机制：

1. **信息—能量效率瀑布与风冷退化（练习 24-20）**：活跃训练池硅片理论峰值算力为 $28,672 \times 2,250\ \mathrm{TFLOPS} = 64.51\ \mathrm{EFLOPS}$，经算子分块效率（$72.0\%$）、四维并行通信重叠效率（$61.35\%$，对应 $\mathrm{MFU}=44.17\%$）与集群可用度（$\mathrm{ETTR}=97.6\%$）逐级折算后，端到端硅片有效利用率为 **$43.11\%$**，折合电网侧每焦耳电能产出 **$377.89\ \mathrm{GFLOP/J}$** 有效训练浮点运算（IT 侧为 $423.24\ \mathrm{GFLOP/J}$）。若散热从温水液冷（$\mathrm{PUE}=1.12$）退化为传统风冷（$\mathrm{PUE}=1.45$），在同样 $100.0\ \mathrm{MW}$ 供电红线下可用超节点机柜从 $496$ 柜缩减至 **$372$ 柜**（损失 $8,928$ 张 GPU），`10T` 旗舰预训练工期从 $62.4$ 天拉长至 **$90.7$ 天**，直接突破季度交付窗口。
2. **电网电价上涨 $40\%$（$65 \to 91\ \mathrm{USD/MWh}$）对冲（练习 24-21）**：若不做调整，三年期电费从 $170.82\mathrm{M\ USD}$ 升至 $239.15\mathrm{M\ USD}$（总 TCO 升至 $2{,}099.15\mathrm{M\ USD}$）。引入 $200\ \mathrm{MWh}$ 磷酸铁锂储能系统（`BESS`，三年摊销 $36.00\mathrm{M\ USD}$，峰谷电价差套利三年节省 $20.80\mathrm{M\ USD}$）并开启第 24.6 节访存受限阶段核心降频（平均电网取电下降 $7.5\%$，三年节电 $17.94\mathrm{M\ USD}$，词元吞吐仅微降 $0.6\%$），可将对冲后总 TCO 收敛在 **$2{,}096.41\mathrm{M\ USD}$**，并使推理池波谷共享后净词元成本稳定在 **$0.60\ \mathrm{USD/1M\ tok}$**。
3. **`HBM4` 供应受限致单卡显存与带宽减半（$192\ \mathrm{GB}\to 96\ \mathrm{GB}$）重配（练习 24-22）**：当单卡显存与带宽折半（整机三年期硬件 CapEx 同步下降 $12\%$ 至 $1{,}636.80\mathrm{M\ USD}$，单卡时租降至 $1.93\ \mathrm{USD/(GPU\cdot h)}$）时，通过 `DeepEP` 两级通信将 Decode 实例从双柜 `EP144` 扩展为四柜 **`EP288`**（聚合显存带宽恢复至 $1,152\ \mathrm{TB/s}$，单卡权重分片降至 $18.06\ \mathrm{GB}$，剩余 KV 池 $65.94\ \mathrm{GB}$），配合 `QuaRot` `FP4` KV 量化与 `PD` 机柜重配（从 `34P:48D` 调整为 `26P:56D`），可在满足 $\mathrm{TPOT}\le 20\ \mathrm{ms}$ 的前提下维持日产 **$184.0\ \mathrm{B}$ 词元**、预训练工期 **$68.8$ 天**（含 `RLVR` 共 $87.3$ 天 $<90$ 天）以及 **$0.65\ \mathrm{USD/1M\ tok}$** 的净生产成本（纯推理池摊销 $1.49\ \mathrm{USD/1M\ tok}$，在 $2.00\ \mathrm{USD/1M\ tok}$ 混合售价下保持 **$67.5\%$** 净毛利率）。
