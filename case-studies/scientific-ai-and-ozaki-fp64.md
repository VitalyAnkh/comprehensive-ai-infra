# 低精度张量核双精度数值仿真与超算显存原位耦合

> 关联章节：[第 22 章 · 科学计算智能系统](../manuscripts/22-科学计算智能系统.md)（22.5–22.6 节）
> 复现命令：`python3 calculations/calc.py science-ozaki-coupling`、`python3 experiments/ch22/22-04/run.py`、`python3 experiments/ch22/22-05/run.py`

## 1. 工程背景：AI 加速器的“双精度收缩”与混合超算 I/O 瓶颈

随着新一代智算芯片（如 NVIDIA Blackwell `B200/B300`、`Vera Rubin` 与 TPU `Ironwood`）将晶体管预算向 `FP8`、`NVFP4` 与 `INT8` 张量核倾斜，原生 IEEE 754 `FP64` 双精度峰值算力与低比特整数张量核峰值算力的剪刀差迅速扩大。典型旗舰配置下，单卡稠密 `INT8` 张量核吞吐达 $4,500\ \mathrm{TOPS}$，而原生 `FP64` 单元仅保留 $40.0\ \mathrm{TFLOPS}$，二者峰值吞吐比达到 $112.5\times$。然而，密度泛函理论（DFT）哈密顿矩阵对角化、耦合簇量子化学以及刚性偏微分方程隐式线性求解对 53 位尾数动态范围高度敏感，直接降级至 `BF16/FP32` 会导致自洽场迭代失稳或本征谱失真。

与此同时，在大气—海洋高分辨率耦合预报或计算流体力学（CFD）次网格湍流闭合中，若传统 MPI C++/Fortran 数值求解器与 PyTorch 神经代理模型（或驱动假设生成的 `Qwen3-8B` / `DeepSeek-V3` 科学推理底座）通过并行文件系统交换三维物理场，每时间步数百 GB 的序列化与磁盘读写会主导端到端墙钟时间；而在多步自回归神经推演中，缺乏硬物理守恒约束的软惩罚残差会呈指数或线性累积，破坏长周期积分的物理可信度。

## 2. 有符号中心化 Ozaki 尾数切片与 INT32 无溢出边界

有符号中心化 `Ozaki` 方案（Ootomo et al., SC '24）不修改硬件电路，而是将双精度矩阵 $A \in \mathbb{R}^{M \times K}$ 与 $B \in \mathbb{R}^{K \times N}$ 沿内积维对齐行/列最大指数后，采用就近偶数有符号舍入递推提取 $S$ 个取值在 $[-127, 127]$ 内的 `INT8` 切片矩阵：

$$
A \approx \sum_{p=1}^{S} \operatorname{diag}\!\left(2^{\mathbf{e}_A^{(p)}}\right) A^{(p)}, \qquad B \approx \sum_{q=1}^{S} B^{(q)} \operatorname{diag}\!\left(2^{\mathbf{e}_B^{(q)}}\right)
$$

1. **硬件 `INT32` 累加器严格零溢出条件**：单次 `INT8` 乘积绝对值上限为 $127 \times 127 = 16,129$。由于有符号 32 位整数最大正值为 $2^{31}-1 = 2,147,483,647$，只要内积维满足
   $$K \le \left\lfloor \frac{2^{31}-1}{127^2} \right\rfloor = 133,144$$
   张量核内部的整点累加便不会发生任何溢出或舍入截断。
2. **三角截断计算代价与实测加速比**：由于中心化舍入将残差绝对值折半，每个切片平均推进约 $7.4\text{–}7.5\ \mathrm{bits}$ 有效尾数精度。取 $S = 7$ 时，仅需计算满足 $p + q \le S + 1 = 8$ 的上三角交叉项，合计调用 `INT8` GEMM 次数为
   $$N_{\mathrm{GEMM}}(7) = \frac{7 \times 8}{2} = 28$$
   在 $112.5\times$ 峰值算力比硬件上，纯计算理论加速上限为 $112.5 / 28 \approx 4.02\times$。对 $M=N=K=8,192$ 的稠密双精度矩阵乘，计入切片拆分与 `FP64` 幂次归约的片外访存开销后，端到端实测加速比为 **$3.68\times$**（等效双精度吞吐 **$147.2\ \mathrm{TFLOPS}$**），有效尾数精度达 **$51.8\ \mathrm{bits}$**。若需覆盖完整 $53.0\ \mathrm{bits}$ IEEE 双精度尾数，可将切片数增至 $S = 8$（$36$ 次 GEMM，纯计算上限 $3.125\times$）。

## 3. DLPack 显存原位零拷贝耦合与守恒律拉格朗日投影

在 `1,024` 张 GPU 上运行的全球高分辨率海气耦合系统中，单个耦合步需跨求解器与神经参数化模块交换 $384.0\ \mathrm{GB}$ 三维边界状态场（平均单卡 $375.0\ \mathrm{MB}$）：

| 耦合与物理约束维度 | 传统落盘中转 / 无约束自回归 | 显存原位零拷贝 + 守恒投影 | 核心工程收益 |
| :--- | :---: | :---: | :--- |
| **步间数据交接路径** | MPI 聚合写 Lustre/NVMe 再由 Python 反序列化读取 | 同节点/同进程 GPU 显存指针通过 `DLPack` / `CUDA IPC` 直接移交 | 消除主机内存拷贝、序列化与并行文件系统双倍带宽占用 |
| **`384 GB` 耦合耗时** | $58.2\ \mathrm{s}$ | **$0.41\ \mathrm{s}$** | 步间耦合提速 **$142.0\times$**（仅含流同步与边界 Halo 规整） |
| **`500` 步质量相对漂移** | $11.4\%$（触发非物理压力波失稳） | **$4.2 \times 10^{-13}$（$< 10^{-12}$）** | 在双精度加权求积下严格满足离散质量与能量通量守恒 |
| **单步推理额外延迟** | 基准 $0.0\%$ | **$+3.1\%$** | 将小规模拉格朗日乘子归约与逐格点修正融合进尾声内核 |

给定离散积分权重向量 $\mathbf{w}$ 与初始守恒总量 $M_0 = \mathbf{w}^\top \mathbf{u}_0$，神经算子单步预测场 $\hat{\mathbf{u}}$ 在加权欧氏范数下的最小扰动正交投影解析解为 $\mathbf{u}^{\mathrm{proj}} = \hat{\mathbf{u}} - \frac{\mathbf{w}^\top \hat{\mathbf{u}} - M_0}{\|\mathbf{w}\|_2^2}\mathbf{w}$。该线性修正仅需一次全网格点积归约与一次融合乘加写回，即可在不重训主干网络的前提下消除百步尺度上的系统性质量漂移。
