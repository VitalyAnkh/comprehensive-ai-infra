# 正文书稿

[前言](00-前言.md)介绍写作缘起、作者的 UB 与数据中心网络经历，以及本书的分析方法。前言同时提供五个部分的结构图、逐章导读和阅读前置条件。

二十四章正文以模型训练与推理的完整执行过程连接跨层优化：应用通过模型与上下文表达行为，各层利用计算关系、状态寿命与任务依赖重新选择实现。算子融合、执行复用、设备交接、上下文共享、存储系统与数据工程、智算中心与电力热学、集群可靠性与基准评测、机密计算与可信安全、后训练与强化学习、自主智能体系统、多模态生成与实时语音、具身智能与物理仿真、推荐检索与向量数据库、科学计算智能系统、软硬件协同与新型架构、以及全栈跨层优化与自演进系统将这一主线融入具体推导。各章插图沿用全书统一的 Hands-On Large Language Models 风格，以 SVG、PNG、PDF 提供（全书共 1,021 幅编号章节配图，含导读总图共 1,022 幅）。

各章均以“本章小结”收尾，资料说明移出正文，来源保留为脚注。
