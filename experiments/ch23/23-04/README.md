# 实验 23-04：扩散大语言模型（Block Diffusion LLM）Roofline 相变与动态置信度重掩码

本实验对应第 23 章 23.4.1 节算例 23-14 与算例 23-15，验证：
1. **32B FP8 模型在单张 H100 上生成 $L_{\mathrm{gen}}=512$ 词元（$B=1$）的 Roofline 跃迁**：
   - 标准自回归（AR）解码：512 步串行，每步耗时 `10.00 ms`，总耗时 `5.12 s`，生成速度 `100.0 tok/s`；
   - 半自回归块扩散（`Block Diffusion`，块大小 $K=64$，每块去噪步数 $T_{\mathrm{denoise}}=10$）：仅需 `8` 个块共 `80` 次前向（权重读取减少 `6.40x`），单次前向耗时 `10.80 ms`，总耗时 `0.864 s`，生成速度跃升至 `592.6 tok/s`（提速 `5.93x`；在 8B 模型上达 `1,420.0 tok/s`）。
2. **动态置信度重掩码调度（Confidence Threshold $\gamma = 0.92$）**：
   - 在代码与结构化文本生成中提前终止 `35.0%` 冗余去噪步（平均每块仅需 `6.5` 步，总前向降至 `52` 次），总耗时降至 `0.5616 s`，生成速度进一步跃升至 `911.7 tok/s`（提速 `9.12x`）。
