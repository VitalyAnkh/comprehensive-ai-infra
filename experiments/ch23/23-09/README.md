# 实验 23-09：BitNet b1.58 三值权重紧凑编码（5 权重/Byte）与 T-MAC SIMD 查找表（LUT）能效核算器

本实验对应第 23 章 27.4 节（算例 27-5 与算例 27-6），验证 `BitNet b1.58` 三值权重 $w \in \{-1, 0, +1\}$ 的理论熵（`1.585 bits`）、`5-trits-per-byte`（$3^5 = 243 \le 256$）无损编码（`1.60 bits/weight`，使 `70B` 模型缩至 `14.0 GB`，较 FP16 压缩 `10.0x`），以及 `T-MAC` $g=4$ 预计算激活查找表（Activation LUT）在端侧芯片上实现 `6.4x` 推理提速与 `88.5%` 动态乘法功耗消除。
