# 实验 13-03：大模型质量打分蒸馏杠杆、万亿词元离线合成数据工厂 Roofline 跃迁与沙箱拒绝采样核算器

1. `70B` 教师模型标注 `500 万` 样本蒸馏 `110M` 轻量分类器处理 `500 亿` 文档的三级算力杠杆（`2,170,138.9 -> 38,877.2 GPU-h`，降本 `55.82x`）；
