# 实验 13-02：百 PB 网页提纯漏斗、MinHash LSH (b=16, r=8) S 型碰撞曲线与分布式 GPU 连通分量去重核算器

本实验对应第 13 章 23.1–23.2 节与算例 23-1、23-2、23-3，复算：
1. `100 PB` CommonCrawl 原始 WARC 经七级提纯漏斗产出 `15.0 T` 精品词元（字节留存率 `2.40%`、正文词元留存率 `13.33%`）；
2. MinHash LSH（$M = 128, b = 16, r = 8$）S 型碰撞概率曲线拐点 $s^* = 0.7071$、$s = 0.80$ 捕获率 `94.68%` 与 $s = 0.50$ 误碰率 `6.07%`；
3. 50 亿篇文档（签名 `2.56 TB`、64 卡 All-to-All 洗牌流量 `2.52 TB`）在 GPU `NeMo Curator` 下的 `80.0x` 加速（`148.0 h -> 1.85 h`）与 `4.50x` 成本压降。
