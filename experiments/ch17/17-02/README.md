# 实验 17-02：全模态 E-P-D-G 四池配比、Transfusion 混合掩码效率与 3DGS—DiT 世界模型帧预算复算器

本实验复现第 17 章 17.4.1–17.4.3 节、算例 17-6、算例 17-7 与练习 17-11、17-13、实验 17-14 的核心定量模型：

1. **全模态 `E-P-D-G` 四池异构解耦配比与 EC 缓存命中率敏感度（算例 17-6 & 练习 17-11，锁定 [`case-studies/multimodal-stage-placement.md`](../../../case-studies/multimodal-stage-placement.md)）**：
   - 在 4 卡节点（单张 `E` 卡 $\mu_{\mathrm{img}} = 12\ \mathrm{img/s}$、单张 `PD` 卡 $\mu_{PD} = 4\ \mathrm{req/s}$）下，单图基线最优配比为 `(1, 3)`（吞吐 **$12.0\ \mathrm{req/s}$**），开启 $h = 75\%$ EC 缓存后单张 `E` 卡有效支撑速率放大 $4\times$ 至 **$48.0\ \mathrm{req/s}$**；
   - 在每请求 4 张图 + `300 MB/s` 交接链路上限（$R_{\mathrm{link}} = \frac{300{,}000{,}000}{32{,}768{,}000} \approx \mathbf{9.16\ \mathrm{req/s}}$）下，零缓存（$h=0$）最优配比为 `(2, 2)`（吞吐 **$6.0\ \mathrm{req/s}$**），而 $h = 75\%$ 下 `(1, 3)` 逆袭为最优（吞吐达链路上限 **$9.16\ \mathrm{req/s}$**）；
   - 将温会话从 36 层主干 KV（$56.25\ \mathrm{MiB}$）降级为 DeepStack EC（$7.8125\ \mathrm{MiB}$）可立即释放 **$86.11\%$** 显存池容量。
2. **统一多模态模型（`Transfusion` / `Show-o` / `Bagel`）分段因果—双向混合掩码与 `<boi>` 跨池迁移（算例 17-7 & 练习 17-13）**：
   - 对总长 $L_{\mathrm{tot}} = 4{,}096$ 的交错序列（前段文本 $L_{T_1} = 1{,}024$ 因果掩码 + 中段图像潜块 $L_{I_1} = 2{,}048$ 块内全双向掩码 + 后段文本 $L_{T_2} = 1{,}024$ 因果掩码），精确计算三段有效注意力词元对面积合计 **$10{,}485{,}760$** 对，占全矩阵 $4{,}096^2 = 16{,}777{,}216$ 的 **$62.5\%$**；
   - 采用 `FlashAttention-3/4`（分块尺寸 $128 \times 128$，全矩阵共 $32 \times 32 = 1{,}024$ 个 Tile）跳过全零块后，仅需执行 $36 + 384 + 228 =$ **$648$ 个活跃 Tile**（节省 $36.72\%$ 矩阵块），已执行 Tile 内部的有效非零利用率高达 **$98.77\%$**；
   - 遇到 `<boi>` 切换至 20 步双向图像扩散时，线性层算术强度从 $1.0\ \mathrm{FLOP/B}$ 跃升至 $2{,}048\ \mathrm{FLOP/B}$；经 $50\ \mathrm{GB/s}$ RDMA 仅需 **$2.88\ \mathrm{ms}$** 即可将前缀 $1{,}024$ 词元的 $144.0\ \mathrm{MiB}$ KV 缓存迁往专属 `G` 池，彻底消除对在线文本解码池（`D` 池）的阻塞。
3. **显式 `3DGS` 几何脚手架 + 受控视频 `DiT` 混合世界模型实时帧率账本（17.4.3 节）**：
   - $120$ 万三维高斯点显式光栅化耗时 $2.4\ \mathrm{ms}$ + 4 步受控视频 DiT 流式拼批耗时 $24.0\ \mathrm{ms}$ + 分块因果 VAE 解码耗时 $4.5\ \mathrm{ms}$，端到端单帧合成耗时 **$30.9\ \mathrm{ms}$**（稳态帧率 **$32.36\ \mathrm{FPS} > 30\ \mathrm{FPS}$**）。
