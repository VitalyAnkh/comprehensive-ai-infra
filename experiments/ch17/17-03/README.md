# 实验 17-03：自回归流式因果视频世界模型（CausVid / Oasis / Matrix-Game）块因果 KV 滚动窗口与 PAB/TeaCache 特征复用仿真

## 实验目标
复现并验证第 17 章 17.4.3 节新增专题与 **算例 17-8**（以及 **练习 17-15**、**实验 17-16**）的全部锁定工程指标：
1. **块因果滚动 KV 缓存池（`1 Sink + 5 Rolling Window`）**：在 720p（`1280x720`，每块 3 帧 RGB = `3,600` 个时空词元）下，维护 1 个常驻首块 Attention Sink 与 5 个近期环形滚动窗口块（共 `6` 个块、`21,600` 个活跃历史词元），将 8 层跨块时间注意力 KV 锁定为 `1.3184 GiB`（全 28 层为 `4.6143 GiB`），较 10 分钟（`4,000` 个块）无界累积的 `878.91 GiB` 严格压缩 **`666.67x`**；
2. **金字塔注意力广播（PAB）与 TeaCache 跨步特征复用**：在 4 步分布匹配蒸馏（DMD）去噪中，将 DiT 单块耗时从全量计算的 `168.0 ms` 压缩至 `96.0 ms`（`42.0 + 18.0 + 2.0 + 34.0 ms`），叠加 `18.0 ms` 流式因果 VAE 解码后，单块（3 帧）总耗时从 `186.0 ms`（单帧 `62.0 ms`，`16.13 FPS`）降至 **`114.0 ms`**（单帧 **`38.0 ms`**，稳态帧率 **`26.32 FPS`**，加速 **`1.63x`**），突破 `20 FPS` 实时交互世界模型红线。
