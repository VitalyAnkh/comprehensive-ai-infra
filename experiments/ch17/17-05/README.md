# 实验 17-05：Minitron 结构化剪枝、`32-bit` 位打包知识蒸馏与有界陈旧度异步 Agentic RL

本实验对应第 17 章 17.5.2 节、17.6 节、算例 17-12、算例 17-13 与实验 17-18，复现：
1. `Qwen3-32B`（$V=151{,}936$）向 `16B` 学生模型蒸馏 `200B` 词元时，全词表 BF16 Logits（`60.7744 PB`）、未打包 `int32+BF16` Top-128（`153.60 TB`）与 `18-bit ID + 14-bit FP14` 紧凑 `32-bit` 位打包 Top-128（`102.40 TB`，压缩比 **`593.5x`**）的存储账本，以及离线预生成与在线 `NVFP4` 教师共置推理在 **`1.88` 轮（epochs）**处的成本盈亏翻转点；
2. `32-bit` 位打包编解码无损验证：检验 $V=151{,}936 < 2^{18}=262{,}144$ 下词元 ID 零误差恢复及 FP14 对数几率相对量化误差；
3. `32` 轮代码修复 Agentic RL 下，同步屏障导致的 **`68.0%`** GPU 空闲气泡与有界陈旧度（$\Delta_{\max}=3$）异步流水带来的 **`2.64x`** 策略更新吞吐加速。
