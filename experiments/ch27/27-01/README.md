# 实验 27-01：晶圆级/全片上 SRAM 芯片（WSE-3 / Groq LPU）vs. HBM GPU 的延迟—并发度 TCO 交叉点求解器

本实验对应第 27 章 27.1 节与 27.2 节（算例 27-1、算例 27-2 与算例 27-3），核算全片上 SRAM 架构（`1,850.0 tok/s`，较 4x H100 `164.7 tok/s` 提速 `11.23x`）与 HBM 架构的每百万词元成本（$\mathrm{USD/MTok}$）盈亏平衡并发度 $B_{\mathrm{cross}} = 14.2$，以及 3D-SRAM 硅穿孔（TSV）热阻温升与 320 颗 SRAM 芯片静态周期级确定性流水线零排队抖动。
