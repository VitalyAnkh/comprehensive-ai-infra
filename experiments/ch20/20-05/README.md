# 实验 20-05：异构机器人 SoC 片上缓存（SLC）分区隔离与闭环神经世界模型碰撞包络回归评测器

本实验复现第 20 章 20.5.1–20.5.2 节算例 20-9、算例 20-10 以及练习 20-17、实验 20-18 的全部锁定工程指标（并与 `calculations/results/ch20-embodied-wcet-sim.json` 同源对齐）：

1. **单颗边缘异构 SoC 三引擎并发的 SLC 路分区与内存控制器 QoS 配额（算例 20-9）**：
   - 在集成 `64 MiB`、`16-way` 系统级缓存（每路 `4 MiB`）与 `273 GB/s` 统一内存控制器的边缘异构 SoC 上并发运行双目 `PVA`、`GPU` VLA 慢系统与实时核 `1 kHz` 全身力控 MPC（截止期 $1.00\ \mathrm{ms}$，热工作集 `3.2 MiB`）；
   - 未隔离竞争下 GPU 大流量冲刷 SLC 并阻塞 DRAM 队列，导致 `1 kHz` MPC 的最坏执行时间恶化至 **$1.82\ \mathrm{ms} > 1.00\ \mathrm{ms}$**（违约）；
   - 通过硬件 SLC 路分区（为实时核锁定 `2 ways = 8 MiB` 专属缓存）+ 内存控制器 `Urgent` 抢占队列与非实时总带宽整形（上限 `205 GB/s`，占峰值 `75.1%`），`1 kHz` MPC 的 WCET 收敛至 **$0.41\ \mathrm{ms} \le 1.00\ \mathrm{ms}$**（加速 **$4.44\times$**）。
2. **64 卡动作条件闭环神经世界模型（`WorldEval / 3DGS + Action-Conditioned Video DiT`）回归评测与包络拦截（算例 20-10）**：
   - 面向 `1,000` 个长程操作场景 × `100` 次扰动闭环（共 **`100,000` 条闭环轨迹**）：64 卡集群仅需 **$0.40\ \mathrm{h}$**（`24.0` 分钟，`25.6 GPU-h`，成本 **$\$768.00$**），对比 10 工位真机实测（耗时 `333.33 h`，总成本 **$\$111,360.00$**）实现 **$145.0\times$ 成本压缩**与 **$833.33\times$ 墙钟提速**；
   - 复现“开环 MSE 倒挂陷阱”：策略 B 离线开环动作 MSE 更低（`0.0041` vs. 策略 A `0.0048`），但闭环碰撞包络越界率高达 **$14.2\%$**（策略 A 仅 **$1.1\%$**），闭环成功率仅 **$54.0\%$**（策略 A 为 **$89.5\%$**）。
3. **练习 20-17 与实验 20-18 扩展核验**：
   - `32 MiB`、`16-way` SLC 下 `5.4 MiB` 实时工作集最小隔离路数为 **`3 ways`（`6 MiB`）**，非实时限速配额 **$140.80\ \mathrm{GB/s}$**，WCET 从 `2.15 ms` 降至 **$0.48\ \mathrm{ms}$**；
   - `128` 卡集群运行 `250,000` 条回归轨迹基线耗时 **$0.50\ \mathrm{h}$**（成本 **$\$1,920.00$** vs. 真机 **$\$278,400.00$**，压缩 **$145.0\times$**），启用碰撞包络早期截断（Early-Stop）后再省 **$21.50\%$** 机时至 **$0.3925\ \mathrm{h}$**（成本 **$\$1,507.20$**）。
