# 实验 14-01：全生命周期过度训练最优配比、K192 预注册证伪与 NeuSight 阶段校准复核器

本实验对应第 14 章 `练习 14-8`、`实验 14-12` 与 `实验 14-15`，仅依赖 Python 3 标准库即可独立运行：

1. **Beyond-Chinchilla 推理感知算力分配复算**：核算 $32\mathrm{B}$ 基准模型与 $20\mathrm{T}$ 词元超配训练 $8\mathrm{B}$ 模型的盈亏平衡推理词元量（$3.0\mathrm{T}$ 词元 / $150.0$ 天）及两年服役期净节省金额（$348$ 万美元）；
2. **K192 预注册证伪复核**：校验实验 `13-07` 的 10 对配对比值，验证中位数 $R = 0.693141 < 0.70$ 并输出 `refuted_in_scope`；
3. **NeuSight 阶段归因校准检查**：验证两阶段 `[8, 2] ms` vs. `[6, 4] ms` 在端到端总误差为 $0\%$ 时掩盖的 $33.33\%$ 与 $50.00\%$ 逐阶段误差，以及阶段一提速减半后的预测偏差（$6.0\ \mathrm{ms}$ vs. $7.0\ \mathrm{ms}$）。
