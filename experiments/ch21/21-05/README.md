# 实验 21-05：万亿稀疏嵌入表布谷鸟频次准入过滤与无锁 Epoch 在线热更新模拟器

本实验对应第 21 章 21.6 节算例 21-9 与算例 21-10，验证：
1. **布谷鸟无碰撞频次准入过滤器（$\tau = 5$）与 30 天指数衰减淘汰**：
   - 在日新增 `40 亿`次曝光点击流、未过滤 30 天原始稀疏表 `2.40 TB`（`2,400.0 GB`）工况下，频次阈值 $\tau = 5$ 拦截出现不足 5 次的一次性噪声 ID（准入保留率 `36.5%`），叠加 30 天不活跃过期回收因子 `0.8630` 后，常驻活跃嵌入表缩减 `68.5%` 至 `756.0 GB`。
2. **每秒 250 万次增量向量流式更新下的分段读写锁 vs. 无锁 Epoch 双缓冲切换**：
   - 原地分段读写锁在高并发千次扇出查表下引发读路径写锁排斥与护航效应，使在线请求查表 `P99` 尾延迟升至 `18.4 ms`；
   - 基于 RCU / Epoch-Based Reclamation（`EBR`）的无锁双槽原子指针发布将查表 `P99` 稳定维持在 `1.15 ms`（尾延迟降低 `16.0x`），3-Epoch 宽限期回收池与影子槽位总额外内存开销仅 `+6.2%`。
