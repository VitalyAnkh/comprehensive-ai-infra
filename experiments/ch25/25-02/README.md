# 实验 25-02：Meta HSTU 随机序列长度压缩（Stochastic Length）与 M-FALCON 千级候选微批前缀摊销

本实验对应第 25 章 25.2 节算例 25-3 与算例 25-4，验证：
1. **HSTU 随机序列长度压缩（Stochastic Length，$\beta = 0.75$）**：
   - 将长尾重度用户 `8,192` 行为序列压缩为有效保留长度 `5,410`（近期 `2,048` 全量保留 + 远期幂律采样），二次方点积聚合注意力计算复杂度降低 `56.2%`（`56.25%`），而 NDCG@10 损失 `< 0.04%`。
2. **M-FALCON 候选集微批前缀摊销（$L_{\mathrm{hist}}=4,096$ 历史词元 + $M=1,024$ 召回候选物品）**：
   - 传统逐物品独立交叉打分：`1,024 x 1.376 = 1,409.3 TFLOPs`；
   - M-FALCON 历史前缀 KV 共享 + 候选非因果对角掩码并行打分：历史前缀仅编码 1 次（`1.376 TFLOPs`）+ 候选微批（`30.084 TFLOPs`）= `31.46 TFLOPs`（算力缩减 `44.80x`），单张 H100 吞吐达 `485 QPS`（每秒打分 `496,640` 个候选物品，P99 延迟 `11.8 ms`）。
