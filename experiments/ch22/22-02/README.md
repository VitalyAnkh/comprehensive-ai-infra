# 实验 22-02：全双工语音随时打断（Barge-in）播放游标对齐 KV 回滚、实时音视频微块交错与 1 小时声学码本剥离模拟器

本实验复现第 22 章 22.3–22.4 节、算例 22-4、算例 22-5 与练习 22-6 至 22-10 的核心定量模型与算法：

1. **随时打断（Barge-in）下按客户端播放 RTP 游标对齐的 KV 缓存精确回滚（算例 22-4）**：
   - 服务端超前生成至第 $k_{\mathrm{srv}} = 65$ 帧（$t_{\mathrm{srv}} = 5,200.0\ \mathrm{ms}$），而客户端实际播放游标位于 $t_{\mathrm{play}} = 4,320.0\ \mathrm{ms}$（即第 $k_{\mathrm{play}} = 54$ 帧），在途未播超前量为 $\Delta k = \mathbf{11\ \text{帧}}$（**$880.0\ \mathrm{ms}$**）；
   - 用户在 $t_{\mathrm{play}} = 4,320.0\ \mathrm{ms}$ 开口打断时，边缘网关立即排空 $11$ 帧未播语音，服务端在 **$0.12\ \mathrm{ms}$** 内将 KV 块表与内心独白历史回滚至第 $54$ 帧（精确剔除 $11 \times 17 = \mathbf{187\ \text{个}}$ 未被用户听到的超前词元），从第 $55$ 帧无缝接纳新语音。
2. **实时视频（$1\ \mathrm{FPS}$）+ 全双工音频（$12.5\ \mathrm{Hz}$）的交错分块预填充（算例 22-5）**：
   - 每秒 $256$ 个视觉 Patch 词元若在单帧内整块插入（耗时 $72.0\ \mathrm{ms}$），会使当帧总耗时飙升至 $11.5 + 72.0 = \mathbf{83.5\ \mathrm{ms} > 80.0\ \mathrm{ms}}$（触发音频断流爆音）；
   - 拆分为 $8$ 个微块（每帧插入 $32$ 个视觉词元，耗时 $9.0\ \mathrm{ms}$）交错注入后，最坏单帧耗时压至 **$20.5\ \mathrm{ms} \ll 80.0\ \mathrm{ms}$**（帧耗时峰值降低 **$4.07\times$**）。
3. **1 小时连续音视频全双工通话的滚动声学码本与过期视觉帧剥离（算例 22-5）**：
   - 1 小时（$3,600\ \mathrm{s} = 45,000$ 音频帧）全量保留需 $765,000$ 音频/文本词元 $+$ $921,600$ 视觉词元 $= \mathbf{1,686,600\ \text{词元}}$；
   - 仅保留最近 $10\ \mathrm{s}$（$125$ 帧）滑窗内的声学残差码本（$q_2\dots q_8$）与视觉帧，对历史轮次仅保留语义首码本（$q_1$）与内心独白文本锚点（每帧 $3$ 词元），可将 1 小时常驻词元数压降至 **$139,310\ \text{词元}$**（纯音频压降至 $136,750$ 词元，省 **$82.12\%$**；音视频全模态省 **$91.74\% > 85\%$**）。
