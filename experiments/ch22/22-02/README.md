# 实验 22-02：百万碱基基因组 FlashFFTConv、全球气象 2D 网格 Halo 交换重叠与五大科学领域跨尺度统一账本

本实验对应第 22 章 22.3–22.5 节与算例 22-3、22-4、22-7，复算：
1. `Evo 2` 40B 在百万单核苷酸（$L = 1,048,576$）分辨率下，传统二次方注意力（`36,028.8 TFLOPs/layer`）vs. `FlashFFTConv`（`1,735.17 GFLOPs/layer`，序列混合算子算力压降 `20,763.8x`，整层端到端提速 `28.5x`）；
2. `SFNO` 全球气象大模型（$0.05^\circ$，$3600 \times 7200$ 网格，64 卡 $8 \times 8$ 二维域分解）的子域周界 Halo 交换体积（`5.53 MB` / `0.18 ms` vs. 内部计算 `14.20 ms`，通信计算比 `1.27%`，暴露通信开销 `0.00 ms`）；
3. 五大科学计算领域（生物大分子结构、百万碱基基因组、全球气象网格、量子化学双精度矩阵与核聚变亚毫秒控制）跨尺度算术强度、显存复杂度与通信占比统一核算账本。
