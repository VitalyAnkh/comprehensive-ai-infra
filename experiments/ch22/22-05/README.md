# 实验 22-05：超算与神经代理 DLPack 显存原位零拷贝耦合及物理守恒律拉格朗日投影

本实验对应第 22 章 22.6.2 节、算例 22-9、算例 22-10 以及练习 22-15、22-16，复算并数值验证：
1. 全球高分辨率大气—海洋耦合模式（`1,024` 卡集群每步交换 `384.0 GB` 边界场，单卡 `375.0 MB`）在并行文件系统落盘中转（`58.2 s`）vs. 同节点 GPU 显存 `DLPack / CUDA IPC` 零拷贝原位耦合（`0.41 s`，端到端提速 `142.0x`）的时间预算账本；
2. 多步自回归神经 PDE 推演（`500` 步）中，无守恒约束导致总质量累计漂移 `11.4%` vs. 融合拉格朗日正交守恒投影算子（额外单步耗时 `+3.1%`）将质量相对误差严格约束在 `4.2e-13`（`< 1e-12`）以内。
