# 实验 22-04：有符号中心化 Ozaki 尾数切片在 INT8 张量核上仿真 FP64 双精度矩阵乘

本实验对应第 22 章 22.6.1 节、算例 22-8 以及练习 22-13、22-14，复算并数值验证：
1. 在 `INT8 Tensor Core = 4,500 TOPS`、原生 `FP64 = 40.0 TFLOPS`（算力峰值比 `112.5x`）的新一代 AI 加速器上，有符号中心化 `Ozaki` 方案（切片取值 `[-127, 127]`）保证硬件 `INT32` 累加器无溢出的最大内积维度上限 $K_{\max} = \lfloor (2^{31}-1) / 127^2 \rfloor = 133,144$；
2. 采用 $S = 7$ 个尾数切片（共 $\frac{7 \times 8}{2} = 28$ 次三角截断 `INT8` GEMM，纯计算加速比上限 `4.02x`）仿真 `8192 x 8192` 双精度矩阵乘，实现 `51.8 bits` 有效尾数精度、端到端 `3.68x` 实测加速（等效双精度吞吐 `147.2 TFLOPS`）；
3. 在确定性双精度测试矩阵上执行真实有符号中心化尾数切片与 `INT32` 精确累加重构，验证相对 Frobenius 范数误差低于 `1e-15`。
