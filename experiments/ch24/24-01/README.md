# 实验 24-01：FlashMLA 非对称头维（512+64）乒乓流水带宽利用率（3,000 GB/s）与 DeepGEMM 二级累加核算器

本实验复现第 24 章 29.1 节的核心量化结论：
1. **FlashMLA**：矩阵吸收后每词元 KV 缓存仅需读取 $512 + 64 = 576$ 个 BF16 元素（`1,152 B/token`，较标准 MHA `32,768 B/token` 压缩 **`28.44x`**），在 H800（峰值 `3,350 GB/s`）上通过双 Warpgroup 乒乓流水实测达到 **`3,000.0 GB/s`（利用率 `89.55%`）** 与 **`580.0 TFLOPS`（屋脊上限 `94.2%`）**；
2. **DeepGEMM**：运行期 JIT 形状常量化将单线程寄存器从 `248` 降至 **`192` 个**，FP8 二级累加每 `128` 周期插入 `4` 周期 `FFMA`（周期占比 **`3.12%`**），实现 **`1,358.0 TFLOPS`** 吞吐。
