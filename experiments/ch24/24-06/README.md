# 实验 24-06：100 MW 智算工厂五大部类全栈联立规划、四大物理守恒律与反事实敏感度校验器

本实验对应第 24 章 24.8 节（与 `python3 calculations/calc.py ai-factory-capstone` 同源对齐），对《深入理解 AI Infra：量化分析与系统设计》收官的 **100 MW 智算工厂（AI Factory）** 进行五大架构部类端到端联立核算与反事实压力测试：

1. **百兆瓦级电热与超节点切分基线（算例 24-12）**：在 $100.0\ \mathrm{MW}$ 园区变电站红线与 `800V HVDC` + `ASHRAE W45` 温水液冷（$\mathrm{PUE}=1.12$）下，核算出 $89.29\ \mathrm{MW}$ IT 总功率预算（$7.45\ \mathrm{MW}$ 光交换与 `3FS` 存储 + $81.84\ \mathrm{MW}$ 共 $496$ 台 `72-GPU` 液冷机柜、合计 $35,712$ 张 GPU），精确切分为 $400$ 柜训练池（$28,672$ 张活跃训练卡 + $128$ 张柜内热备）、$82$ 柜在线推理与波谷 `RL` 采样池（$5,904$ 张）以及 $14$ 柜整柜热备池（合计 $1,136$ 张泊松热备卡 $=3.18\%$，$\mathrm{ETTR}=97.6\%$）；
2. **双轨预训练工期与三年期 Tokenomics 账本**：活跃训练池持续输出 $27.81\ \mathrm{EFLOPS}$，在 $62.4$ 天内完成 `10T/380B` 旗舰稀疏模型 $60\ \mathrm{T}$ 词元预训练（叠加 $18.5$ 天 `RLVR` 合计 $80.9$ 天），在 $2.75$ 天内完成 `1T/44B` 敏捷模型 $25\ \mathrm{T}$ 词元预训练；三年期总成本 $2{,}030.82\mathrm{M\ USD}$（折合 $2.16\ \mathrm{USD/(GPU\cdot h)}$），日产 $216.5\ \mathrm{B}$ 词元下纯推理池摊销单价 $1.41\ \mathrm{USD/1M\ tok}$，波谷共享 `RL` 后净单价降至 $0.61\ \mathrm{USD/1M\ tok}$；
3. **四大物理守恒律端到端效率瀑布与三组反事实敏感度（练习 24-20、24-21、24-22）**：校验从电网输入功率到有效训练算力的逐级效率瀑布（风冷 $\mathrm{PUE}=1.45$ 退化冲击）、电价上涨 $40\%$ 下的 `BESS` 储能削峰与访存受限段降频对冲，以及 `HBM4` 显存减半（$192\ \mathrm{GB}\to 96\ \mathrm{GB}$）下的 `EP288` 扩域与 `PD` 机柜重配。
