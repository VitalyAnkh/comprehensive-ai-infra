# 实验 18-03：GUI 智能体增量脏矩形 ROI 视觉缓存与多智能体 DAG 关键路径投机工具预执行复算器

本实验复现第 18 章 18.4.2 节：
- **算例 18-6**：30 步 GUI 智能体（`OSWorld` / `WebArena`）增量脏矩形 ROI 视觉词元缓存（`12.5%` 脏块）+ 可交互 Set-of-Marks DOM 剪枝（`3,600 -> 450` 词元），将累计多模态词元从 `180,000` 压缩至 `24,600`（`7.32x` 压缩，省 `86.33%`），ViT 视觉编码耗时从 `1,350.00 ms` 缩减至 `251.62 ms`（`5.37x` 加速）。
- **算例 18-7**：4 阶段多智能体工作流 DAG 关键路径投机工具预执行（`600 ms` 模型推理 + `1,400 ms` 外部工具、`80%` 命中率、命中净耗时 `1,050 ms`、误判 `12.0 ms` Firecracker CoW 快照回滚），将期望关键路径延迟从 `8,000.00 ms` 压缩至 `4,969.60 ms`（`1.61x` 提速，降低 `37.88%`），盈亏平衡命中率仅 `1.25%`。
- **练习 18-11 与实验 18-12**：40 步高分辨率桌面增量缓存（`320,000 -> 35,680` 词元，`8.97x` 压缩；ViT `2,400.00 -> 372.00 ms`，`6.45x` 加速）与 5 阶段 DAG 投机预执行（`10,000.00 -> 6,643.75 ms`，`1.51x` 提速）。
