# 实验 18-05：多智能体 DAG 扇出尾延迟放大、关键路径调度与流式 JSON 投机工具执行

本实验对应第 18 章 18.6 节、算例 18-9、算例 18-10、练习 18-15 与实验 18-16，复现：
1. 多智能体并行扇出（Fan-out）尾延迟次序统计量放大：单子智能体长尾响应分布满足 $\mathrm{P99}=6.2\ \mathrm{s}$ 时，$K=12$ 全量同步屏障（All-Join）下的端到端 $\mathrm{P99}$ 飙升至 **`19.8 s`**（且在 $K=16$ 时维持整体 $\mathrm{P99}$ 达标要求单分支达到 **`P99.937`**）；引入关键路径松弛度（Critical-Path Slack）优先级抢占与 `10/12` 法定人数（Quorum）超时优雅降级后，聚合 $\mathrm{P99}$ 收敛至 **`7.4 s`**；
2. 流式 JSON 字段级投机只读工具调用（Speculative Read-Only Tool Execution）：当 `tool_name` 与主查询键流式闭合且只读命中率 $p_{\mathrm{hit}}=0.86$、单次外部检索耗时 $T_{\mathrm{tool}}=245.0\ \mathrm{ms}$ 时，期望节省等待延迟 **`210.7 ms`**，单位有效工具调用额外作废查询比仅为 $(1-0.86)/0.86=$ **`16.3%`**；
3. 副作用工具禁止投机与分布式 Saga 补偿事务验证：确保写操作严格延后至完整 JSON Schema 校验闭合后提交，并在下游步骤失败时按逆序执行幂等补偿动作恢复系统一致性。
