# 实验 18-04：`XGrammar` 上下文无关词表位掩码缓存与 CPU/GPU 异步解码重叠

本实验对应第 18 章 18.5 节、算例 18-8、练习 18-13 与实验 18-14，复现：
1. 词表划分与位掩码容量账本：`Qwen3`（$V=151{,}936$）每请求仅占 $\lceil 151{,}936 / 32 \rceil = 4{,}748$ 个 `uint32` 字（`18,992 B`，即 `18.55 KiB`），并发批大小 $B=64$ 时 PCIe H2D 总载荷仅 **`1.16 MiB`**（对比 `DeepSeek-V3` $V=129{,}280$ 为 `4,040` 个 `uint32` 字 / `16,160 B`）；
2. 上下文无关（Context-Independent）静态掩码预计算与自适应稀疏补丁合并：将约 `99%` 仅依赖当前终结符规则的词元掩码离线预编译进紧凑位图，仅在运行时动态求值不足 `1%` 的栈上下文相关词元；
3. 同步阻塞 FSM 与异步 CPU/GPU 流水线吞吐对比：朴素逐词元 Python/CPU 正则检查在 $B=64$ 下阻塞 **`38.4 ms`**，叠加 **`8.5 ms`** GPU 解码步导致步时间膨胀至 `46.9 ms`（吞吐下降 **`81.9%`**）；而 `XGrammar` C++ 下推自动机异步生成 64 路掩码仅需 **`2.10 ms`**（`32.8125 us/req`），完全隐藏在上一词元 **`8.50 ms`** GPU 前向窗口之内，实现 **`0.0%`** 解码吞吐损失。
